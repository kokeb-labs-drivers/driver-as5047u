Detailed Description

Public types of the AS5047U driver: errors, Result<T>, configuration, decoded registers.

Copyright
Copyright (c) 2026 The driver-as5047u authors. SPDX-License-Identifier: MIT

Everything here is plain data with no platform dependency, so handlers, tests and tools can include it without the driver template. The configuration defaults are the register reset values of a part whose OTP was never burned (datasheet DS000637, "Register Description"), so Config{} describes a freshly powered chip; only the SPI frame format is a driver-side choice.
