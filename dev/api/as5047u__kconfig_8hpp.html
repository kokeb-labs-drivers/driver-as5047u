Detailed Description

Optional ESP-IDF layer: a Config built from the CONFIG_AS5047U_* Kconfig options.

Include this header only where you want menuconfig to choose the defaults; the driver never includes it and no driver signature depends on it. Under ESP-IDF the values come from sdkconfig.h. Without Kconfig every option falls back to the default, so KconfigDefaults() equals Config{}.

Kconfig writes a bool option set to "n" as an absent macro; the "y by default" options are therefore spelled as their negation (CONFIG_AS5047U_DAEC_DISABLE).

One configuration per program (KB-CPP20-018): KconfigDefaults() is an inline function whose body depends on sdkconfig.h and the CONFIG_ macros, so every translation unit of a program must see the same ones. ESP-IDF guarantees that (one sdkconfig per build); the host tests build each Kconfig variant as its own executable. This header is a leaf: no driver header includes it.
