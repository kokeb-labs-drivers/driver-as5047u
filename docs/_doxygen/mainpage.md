# AS5047U Driver API reference {#mainpage}

The classes, types and registers of the AS5047U driver, generated from the headers in `inc/`.

Start with as5047u::AS5047U, the driver, and as5047u::SpiInterface, the base of the port you write. Errors are
as5047u::Error inside as5047u::Result; the configuration is as5047u::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">AS5047U Driver
documentation</a>.
