Detailed Description

Everything EnsureInitialized() and ApplyConfig() write to the chip.

The register defaults are the reset values of an unprogrammed part, so Config{} changes nothing on such a chip. Codes are the raw register field values; the datasheet section of each field gives the table.

Member Data Documentation

◆ frame

FrameFormat as5047u::Config::frame {FrameFormat::Bits24}

Driver side: the frame length of every read (writes are always CRC-protected). **Bits16 reads carry no CRC**: a corrupted reply goes unnoticed, and MISO stuck low (or a chip that hears MOSI as all zeros) reads as angle 0 with no flag bit. Keep the default Bits24 wherever a stuck line must never read as a position (docs/limitations.md).

◆ startup_timeout_ms

uint32_t as5047u::Config::startup_timeout_ms {kPowerOnTimeMs}

Driver side: how long EnsureInitialized() polls DIA, once per millisecond, for every loop to report finished before it fails with NotReady (or NoDevice when DIA never read anything but 0). 0 to kStartupTimeoutMaxMs; 0 checks once and never waits. The default t_pon covers a start made the moment the supply comes up (handbook KB-CPP-124).

◆ write_settings

bool as5047u::Config::write_settings {true}

Driver side: write the settings below in EnsureInitialized(). False leaves the chip as it is, for a part whose OTP is burned: EnsureInitialized() reads the settings back into GetConfig(), so a later setter changes only the field it names.
