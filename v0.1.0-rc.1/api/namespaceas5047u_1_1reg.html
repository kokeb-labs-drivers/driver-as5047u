◆ kDiaReserved

constexpr uint16_t as5047u::reg::kDiaReserved = 1U << 10
inlineconstexpr

DIA bit 10 has no function and reads 0 (Figure 35): a reply with it set does not come from an AS5047U. Bit 13 is not described (the reset value 0xX3C2 leaves bits 15..12 open), so it is not checked; all ones is caught as a line pattern.
