Detailed Description

The SPI port of the AS5047U driver: the CRTP base, the SpiPort concept and the frame layer.

The driver never calls an SDK. It calls hooks on a class you derive from as5047u::SpiInterface<Self>:

Hook Contract
bool EnsureInitialized() noexcept Bring the bus up on the first call; true at once afterwards
bool Transfer(const uint8_t* tx, uint8_t* rx, std::size_t len) noexcept One full-duplex frame, CS low for all len bytes

The port moves raw bytes: it never retries and never interprets a frame. What the chip needs from the bus is below as constexpr values (kSpiMode to kContinuousWord, datasheet DS000637, "SPI Interface (Slave)" and "SPI Timing", Figures 18 and 19); a port checks its settings against them with static_assert (handbook KB-CPP-123). CS must go high between frames, because the chip executes a frame on the rising CS edge and finds its length from the clocks while CS was low. The hooks DelayUs (required) and Log (optional) are described in as5047u.hpp.
