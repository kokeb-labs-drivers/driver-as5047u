◆ Error

enum class as5047u::Error : uint8_t
strong

Why a call failed. Every call of the driver returns one of these in its Result.

Values 0 to 9 are the shared base set; chip-specific values start at 16. The type is [[nodiscard]]: a call whose Error is dropped does not compile quietly (KB-CPP20-037).

Enumerator
Ok 

The call succeeded.

NotInitialized 

EnsureInitialized() has not succeeded yet, or Deinitialize() ran since.

InvalidArgument 

An argument or a Config field is out of range; nothing was sent.

Bus 

A port hook returned false.

Timeout 

The OTP burn did not finish in kOtpBurnTimeoutMs.

DeviceIdMismatch 

Something answers at start-up, but DIA has bit 10 set, which reads 0 on an AS5047U: not this chip.

Crc 

A reply's CRC was wrong, or the chip saw a wrong CRC (ERRFL.CRC_error).

Busy 

Not returned by this driver (the chip has no busy state).

DeviceFault 

ERRFL reports a fault of the measurement path (P2RAM, watchdog, CORDIC, offset compensation): the value is not a measurement.

Unsupported 

Not returned by this driver.

Framing 

The chip saw an SPI framing error (ERRFL.Framing_error).

Command 

The chip saw an invalid command (ERRFL.Command_error).

WriteMismatch 

A register read back different from what was written.

OtpVerify 

The OTP burn finished, but the guard-band read-back differs: do not use the part (datasheet OTP procedure, step 19).

NoDevice 

A reply that a stuck, floating or looped-back line produces: all zeros or all ones with a wrong CRC, an ERRFL with its reserved bit set, an error bit with no error in ERRFL, or a DIA that stayed 0 (KB-CPP-116).

NotReady 

The chip answers, but DIA did not report every loop finished within Config::startup_timeout_ms (KB-CPP-124).

MagnetWarning 

The reply carried the warning bit and ERRFL holds an AGC or magnetic-half warning: the field is out of range and the angle is not a measurement (KB-CPP-127).

DeviceReset 

The chip was reset, or a reset could not be ruled out: after OffCompNotFinished or WDTST in ERRFL, or in CheckForReset(), the settings registers did not hold what the driver wrote. The driver is uninitialised: call EnsureInitialized() again.

◆ FrameFormat

enum class as5047u::FrameFormat : uint8_t
strong

SPI frame length. The chip recognises the length of each frame, so the driver may mix them.

Writes always use a CRC-protected frame: with Bits16 the driver sends writes as 24-bit frames (the datasheet allows 16-bit frames for reads only).

Enumerator
Bits16 

16-bit frames, no CRC: the fastest reads, but a corrupted reply goes unnoticed.

Bits24 

24-bit frames with CRC-8 in both directions. Default.

Bits32 

32-bit frames: a pad byte, then a 24-bit frame (daisy chains).

◆ Verify

enum class as5047u::Verify : uint8_t
strong

Whether a run-time write reads the register back, chosen per call.

A write is the two frames the datasheet needs (command and data, CRC-protected, the reply's error bit checked). ReadBack adds one frame pair per register and fails with WriteMismatch when the chip holds something else: it catches a write the chip lost, or a read-only bit. EnsureInitialized() and ProgramOtp() read their writes back whatever is passed elsewhere.

Enumerator
None 

Command and data frames only. The default: nothing extra on a timed path.

ReadBack 

Read each written register back and compare.
